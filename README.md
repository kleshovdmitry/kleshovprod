# KLESHOVPROD — сайт-портфолио

Готовая статическая страница Дмитрия Клещёва, режиссёра монтажа. **Никаких подписок и платных библиотек:** HTML + CSS + JavaScript, работают и локально, и на бесплатном статическом хостинге.

## Как посмотреть

Откройте файл `index.html` двойным кликом. Понадобится интернет только для воспроизведения видео в Kinescope.

## Настройки сайта (уже заполнены)

Откройте `site-config.js` обычным Блокнотом и измените значения в кавычках:

- `weddingVideo` — ссылка на «Кирилл и Татьяна» уже установлена.
- `anniversaryVideo` — ссылка на «Кузнецовы — 20 лет» уже установлена.
- `telegram` — уже заполнено: `https://t.me/kleshovprod`. Кнопка «Написать в Telegram» работает. При желании можно добавить `email` — адрес электронной почты.

Обе ссылки Kinescope и Telegram уже подключены. Дополнительных изменений для проверки сайта не требуется.

**Важно:** проекты/съёмки/достижения и формулировки, указанные на сайте, должны быть вами подтверждены. Проверьте права на публичное использование кадров, музыки и согласие героев.

## Бесплатная публикация на GitHub Pages

1. Создайте бесплатный аккаунт на GitHub, если его ещё нет.
2. Создайте **публичный** репозиторий с именем `kleshovprod`.
3. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js`, `site-config.js` и папку `assets`.
4. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**. Укажите `main` и `/ (root)`, сохраните.
5. Адрес будет примерно `https://ВАШ-ЛОГИН.github.io/kleshovprod/`.

Хостинг бесплатный, домен не нужен. **Доступность без VPN на конкретных российских провайдерах стоит проверить на реальных телефонах**: гарантировать её для любого зарубежного хостинга нельзя.

## Состав

- `index.html` — структура страницы.
- `style.css` — адаптивный дизайн.
- `script.js` — работа кнопок, окно просмотра видео.
- `site-config.js` — публичные видеоссылки и контакты.
- `assets/kuznetsov-frame.webp` — обрезанный кадр из предоставленного скриншота видеоплеера.

Плеер встроен официальным способом Kinescope (`https://kinescope.io/embed/VIDEO_ID`). Если встраивание ограничено настройками видео, в окне есть ссылка «Открыть отдельно».
